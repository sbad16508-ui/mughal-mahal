# MughalMahalMapApp

A ready-to-run Windows Forms app using WebView2 to display Google Maps for Mughal Mahal Hotel.

## Requirements
- Visual Studio 2022 or later
- .NET 8.0 SDK or later
- Microsoft Edge WebView2 Runtime installed

## Setup
1. Open `WinFormsGoogleMap.sln` or the folder in Visual Studio.
2. Restore NuGet packages.
3. Build and run.

## Package
The project uses the `Microsoft.Web.WebView2` NuGet package.

## Notes
- The map loads automatically when the form opens.
- The WebView2 control is docked to fill the window.
- The map URL is set to the Google Maps location for Mughal Mahal Hotel.
